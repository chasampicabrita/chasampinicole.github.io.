# Portfolio personal — Antonella Chasampoi

Sitio web personal de presentación profesional, con una estética pastel y detalles visuales inspirados en interfaces digitales.

## Cómo abrirlo
1. Descargá y descomprimí el ZIP.
2. Abrí la carpeta `antonella_web`.
3. Hacé doble clic en `index.html` para abrir el sitio en el navegador.

No requiere instalación ni servidor para la vista local.

## Estructura
```text
antonella_web/
├── index.html
├── README.md
├── bitacora_ia.md
├── css/
│   └── estilos.css
├── js/
│   └── script.js
└── assets/
    └── img/
        └── retrato-antonella.jpg
```

## Publicar con GitHub Pages
1. Creá un repositorio público llamado `TUUSUARIO.github.io`.
2. Subí el contenido de esta carpeta (no la carpeta ZIP).
3. En GitHub, abrí Settings → Pages y seleccioná la rama principal como fuente si no se publica automáticamente.
4. Esperá a que GitHub Pages genere el sitio.

Revisá los datos de contacto antes de publicar el sitio en Internet.
